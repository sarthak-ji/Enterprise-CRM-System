# CRM Design System — Reference Guide

A modern, professional SaaS design system for the Enterprise CRM, built on **Tailwind CSS v4** with config-in-CSS tokens, full dark-mode support, and a consistent component vocabulary.

> **Source of truth:** [src/assets/styles/index.css](src/assets/styles/index.css) · [src/design-system/tokens.js](src/design-system/tokens.js)

---

## 1. Philosophy

| Principle | How it's applied |
|---|---|
| **Token-first** | All design values live in `@theme` as CSS variables. No magic numbers in components. |
| **Dark-mode native** | Tokens automatically remap under the `.dark` class — components use semantic names, never raw colors. |
| **Composable** | All primitives use `class` strings (`ds-btn`, `ds-card`, `ds-badge-brand`) — combine with Tailwind utilities. |
| **Accessible** | Universal focus ring, semantic naming, WCAG-AA contrast across both themes. |
| **Performant** | Transitions target only `transform`/`opacity`/`box-shadow`; respects `prefers-reduced-motion` via Tailwind defaults. |

## 3. Typography

| Token | Size | Use for |
|---|---|---|
| `text-xs` | 12px | Badges, helper text |
| `text-sm` | 14px | **Body text (default)** |
| `text-base` | 16px | Long-form content |
| `text-lg` | 18px | Sub-headings, large body |
| `text-xl` | 20px | Card titles |
| `text-2xl` | 24px | Page sections |
| `text-3xl` | 30px | **Page titles (h1)** |

- **Font family:** `Inter` (with system fallbacks)
- **Mono:** `JetBrains Mono`
- **Line heights:** `tight` (1.25), `snug` (1.375), `normal` (1.5), `relaxed` (1.625)
- **Headings** (h1–h4) are pre-typed via `@layer base` with tight letter-spacing.

Use a JS map to bind pipeline stages → tones:

```js
// src/design-system/tokens.js
export const statusMap = {
  new:         { tone: 'brand',   dot: 'ds-status-active' },
  qualified:   { tone: 'success', dot: 'ds-status-active' },
  negotiation: { tone: 'warning', dot: 'ds-status-pending' },
  lost:        { tone: 'danger',  dot: 'ds-status-error' },
};
```

## 12. Hover & Transition Utilities

| Class | Effect |
|---|---|
| `ds-hover-lift` | `translateY(-2px)` + larger shadow on hover |
| `ds-hover-glow` | Brand-tinted glow on hover |
| `ds-press` | `scale(0.97)` on `:active` |
| `ds-link` | Brand color + underline on hover |

All transitions use the smooth easing (`cubic-bezier(0.4, 0, 0.2, 1)`) at `200ms` by default.

### Motion tokens

| Token | Value |
|---|---|
| `--duration-fast` | 120ms |
| `--duration-normal` | 200ms |
| `--duration-slow` | 320ms |
| `--ease-smooth` | `cubic-bezier(0.4, 0, 0.2, 1)` |
| `--ease-spring` | `cubic-bezier(0.34, 1.56, 0.64, 1)` |

### Animation utilities

| Class | Effect |
|---|---|
| `animate-fade-in` | Fade in |
| `animate-slide-up` | 8px up + spring ease |
| `animate-slide-down` | 8px down + spring ease |
| `animate-scale-in` | Scale 0.96 → 1 + spring ease |
| `animate-pulse-soft` | 2s soft pulse (notifications) |

## 14. Accessibility Checklist

- [x] All interactive elements have a focus ring (`--shadow-ring`)
- [x] Color contrast ≥ 4.5:1 for body text in both themes
- [x] Disabled state communicated by both opacity **and** `cursor: not-allowed`
- [x] Hit targets ≥ 40px on all buttons (`ds-btn-md` and up)
- [x] Selection colors themed per mode
- [x] Scrollbars don't take layout space

---

## 15. Do's and Don'ts

✅ **Do**
- Use semantic tokens (`bg-surface`, `text-muted`) over raw colors (`bg-white`, `text-gray-500`)
- Combine `ds-*` classes with Tailwind utilities for one-off adjustments
- Use the `cn()` helper for conditional classes

❌ **Don't**
- Hardcode hex values in component code
- Use raw `bg-blue-500` — pick a semantic token or use the brand palette
- Bypass the focus ring with `outline: none` without a replacement
- Mix multiple badge tones on the same row of data
